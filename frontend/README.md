# 🐜 MoviPay

**MoviPay** é uma plataforma web que conecta **clientes** a **prestadores de serviço** locais — elétrica, limpeza, pintura, jardinagem, mudança e muito mais — com busca em tempo real, chat, orçamentos, pagamentos e um sistema de gamificação próprio chamado **Folhas** 🍃.

Construído em **Next.js (App Router)**, com um sistema visual autoral (tipografia Fraunces + Inter, paleta laranja/verde, modo escuro e microanimações com Framer Motion) inspirado no tema de formigas cortadeiras que carregam folhas — daí o mascote 🐜 e a moeda de desconto do app.

## Comece por aqui

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
